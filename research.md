<h3>PUNCH: Physics-informed Uncertainty-aware Network for Coronary Hemodynamics</h3>

<h3>Physics-Informed Neural Network-Based Inverse Framework for Time-Fractional Differential Equations for Rheology</h3>
<p class="research-authors">Sukirt Thakur, Harsa Mitra, Arezoo M. Ardekani &mdash; <em>Biology</em>, 2025</p>
<p class="research-desc">A PINN framework incorporating time-fractional derivatives to infer physical parameters from sparse and noisy data. Accurately recovers generalized diffusion coefficients and fractional orders, and predicts relaxation behavior in biological tissues with fewer assumptions.</p>

<h3>ELPINN: Eulerian Lagrangian Physics-Informed Neural Network</h3>
<p class="research-authors">Sukirt Thakur, Maziar Raissi</p>
<p class="research-desc">A novel PINN framework coupling Eulerian and Lagrangian perspectives, using particle trajectory data to reconstruct velocity and pressure fields. Evaluated on 2D external flow, 2D internal flow, and 3D flow inside an airplane cabin.</p>

<h3>ViscoelasticNet: A Physics Informed Neural Network Framework for Stress Discovery and Model Selection</h3>
<p class="research-authors">Sukirt Thakur, Maziar Raissi, Arezoo M. Ardekani &mdash; <em>Journal of Non-Newtonian Fluid Mechanics</em>, 2024</p>
<p class="research-desc">A physics-informed deep learning framework that uses velocity flow fields to select constitutive models and learn the stress field for viscoelastic fluids. Works with noisy and sparse data across Oldroyd-B, Giesekus, and linear Phan-Tien-Tanner models.</p>
